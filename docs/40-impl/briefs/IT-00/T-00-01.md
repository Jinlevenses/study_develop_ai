## 1. 목표 (한 문장)

17개 단위 + 루트로 된 pnpm 워크스페이스를 최종 모양(정확 pin·lockfile·루트 스크립트 전부·Biome + GritQL 플러그인·fr-iteration 시드)으로 만들고, 모든 `vitest.config.ts`가 쓰는 testkit preset·무네트워크 setup·고정 시계·시드 PRNG를 구현해 **빈 단위까지 포함한 전 단위의 `typecheck`·`test`가 exit 0**이 되게 한다.

### 4.0 T1 사전 실측 (2026-10-01, 이 컨테이너)

- §4.2의 **모든 pin이 레지스트리에서 해석됨**(`pnpm view <pkg>@<ver> version` 70건 전부 일치). 그래도 1단계에서 다시 확인한다(§4.9 ①).

- vitest 설정 로더는 Node 기본 조건으로 `@fathom/testkit/vitest-preset`을 `dist/`로 해석해 실패한다 → 모든 vitest·Playwright 호출을 `node --conditions=source …` 형태로 쓴다(D-B02). Vite 6+는 `resolve.conditions`를 덮어쓰고 node 환경은 `ssr.resolve.conditions`를 쓰므로 preset은 두 곳 모두 `'source'` + 기본값을 둔다(D-B03).

```ts
export function mulberry32(seed: number): () => number; // seed는 정수(아니면 RangeError), 내부 상태 = seed >>> 0
export type Prng = {
  readonly next: () => number;                                 // [0, 1) — 분리해 rng 포트로 넘겨도 동작(화살표 함수)
  int(minInclusive: number, maxInclusive: number): number;      // min + floor(next() × (max − min + 1)); 정수 아님·min > max → RangeError
  pick<T>(items: readonly T[]): T;                              // items[int(0, len − 1)]; 빈 배열 → RangeError
  shuffle<T>(items: readonly T[]): T[];                         // 복사본에 Fisher–Yates(i = len−1 → 1, j = int(0, i), swap). 입력 불변
};
export function createPrng(seed: number): Prng;
```

- 기준 알고리즘(그대로): `a |= 0; a = (a + 0x6d2b79f5) | 0; let t = Math.imul(a ^ (a >>> 15), 1 | a); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296;`
- 기준값(T1 실측): seed 42 → `0.6011037519201636, 0.44829055899754167, 0.8524657934904099` · seed 1 첫 값 `0.6270739405881613` · seed 42 `int(1,6)` 5회 → `4,3,6,5,2` · seed 7 `shuffle([1,2,3,4,5])` → `[4,2,3,5,1]` · seed 7 `pick(['a','b','c','d'])` → `'a'`.
- 세 파일 모두 export 함수 반환 타입 명시(STD-TS-18), `Date.now()`·`Math.random()` 사용 0(STD-TST-03).
