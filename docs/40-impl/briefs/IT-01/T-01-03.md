### 4.3 CLI (`cli.ts`)

```
check    [--pack <id>[,<id>…]]… [--only V1|V2|V7[,…]] [--release] [--json] [--content-dir <abs>] [--policy-dir <abs>]
build    [--pack …]… [--release] [--json] [--out-dir <abs>] [--content-dir <abs>] [--policy-dir <abs>]

```

- 기본 경로: repo = `fileURLToPath(new URL('../../../', import.meta.url))` · content = `<repo>/content` · policy = `<repo>/policy` · out = `<repo>/dist/packs` · R4 = `<repo>/docs/00-research/R4-curriculum-taxonomy.md`. `--*-dir`은 절대 경로만(상대 = exit 2). 맨 앞 `--` 토큰 1개는 무시(pnpm 인자 전달).
- `--pack`: 쉼표 목록·반복 모두 허용. **전체 트리를 항상 로드**(교차 팩 R-REF·R-DAG 해석)하고, 결과 보고·종료 판정·emit만 선택 팩 파일 + 공용 파일(`templates/**`·`sources/**`)로 한정. 없는 팩 id = exit 2.
- `--only`: V1은 항상 실행(모델 구축 전제). 기본 = V1·V2·V7 전부.
- 출력(사람용, stdout): finding 1줄씩 `<severity> <rule> <file>[#<keypath>] <message>` → 마지막 줄 `content:check packs=<n> files=<n> errors=<n> warnings=<n>`(build는 `packs:build packs=<n> written=<n> errors=<n>`). `--json` = 한 줄 JSON `{ ok, exit, findings[], summary }`. finding 정렬 = `file` → `keypath` → `rule` → `message`(코드 단위 사전순). 엔진 고장은 stderr 한 줄 `packc: <reason>`.
- **종료 코드**: 0 = error finding 0 · 1 = error ≥ 1(warn·info는 무관) · **2 = 엔진 고장**: content 디렉터리 없음·`packs/` 없음·팩 디렉터리 0개·스캔 파일 0개(입력 0 = 2, UT-PACKC-004) · 정책 로드 실패(`loadPolicy('mastery_rules'|'method_policy', 1)` `!ok`) · R4 파싱 결과 0행 또는 형식 위반 · 알 수 없는 서브커맨드·인자·없는 `--pack` · 처리되지 않은 예외. exit 2에서는 아무 파일도 쓰지 않는다.
- 시계: `scaffold --as-of` 생략 시만 `new Date().toISOString().slice(0,10)`. 그 밖 시계·난수·환경변수 0.

### 4.5 V7 바인딩 · 문항 상태 (`validate/v7-binding.ts`) [Brief 결정 — 출제 가능 문항이 있어야 E1-1이 성립]
