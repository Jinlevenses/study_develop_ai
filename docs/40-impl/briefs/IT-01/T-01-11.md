### 4.4 D 채점·정규화 (`domain/grading/ladder/deterministic.ts`·`normalize/basic.ts`)

`gradeDeterministic(format, answerKey, response): Result<DOutcome, { kind: 'response_kind_mismatch' }>`, `DOutcome = { result: 'correct'|'partial'|'incorrect'; score: number; chosen: string | null }`.
- `ox`: `value === answer`. `choice` 단일(mcq·log_read·d4·embedded mcq): `option_keys.length !== 1` 또는 키가 `item.options`에 없음 → `response_kind_mismatch` · 일치 = correct, `chosen = option_keys[0]`. `mcq_multi`: 응답 키 ⊄ options → mismatch · Jaccard(응답, 정답) = 1 → correct / 0 → incorrect / 그 사이 → partial(`score` = Jaccard).
- `short`: 정규화(아래) 응답이 정규화된 `accept` 중 하나와 같으면 correct → 아니면 `accept_regex`(있으면 `new RegExp('^(?:' + re + ')$', 'u')`를 NFC·trim 원문에 적용) → 아니면 `numeric`(응답에서 첫 숫자 토큰 파싱, `|x − v| ≤ tol_abs` 또는 `≤ tol_rel × |v|`, 둘 다 없으면 정확히 같음) → 아니면 incorrect.
- `cloze`: 응답 `blanks` 키 집합 = 정답 키 집합이 아니면 mismatch · 빈칸마다 그 빈칸 `normalize`로 accept 비교 → 맞은 수/전체 = score, 전부 correct / 0 incorrect / 그 사이 partial.
- `code_predict`: `\r\n`→`\n`, 줄마다 끝 공백 제거, 끝 빈 줄 제거 후 정확히 같음.
- `normalizeBasic(s, n: { nfkc: boolean; case: 'sensitive'|'insensitive'; space: 'collapse'|'remove'; strip_josa: boolean })` [Brief 결정 — FR-QST-018 R1 전체(동의어·normalize-200 ≥ 0.98, UT-CT-303)의 기초 부분]: NFC → (nfkc면 NFKC) → trim → 끝 문장부호 `.。!?` 제거 → case insensitive면 `toLowerCase()` → space collapse(`\s+`→`' '`)/remove(전부 제거) → strip_josa면 마지막 어절 끝 조사 1개 제거(긴 것 우선: `에서·으로·이다·은·는·이·가·을·를·의·에·로·와·과·도·만`, 남는 길이 ≥ 1일 때만).
- AI 호출 0(FR-QST-017 [T]). 답안 원문은 로그에 남기지 않는다(STD-LOG-22).

### 4.5 권장 등급·확신도 (`domain/grading/cbm.ts`) [Brief 결정 — FR-QST-024 분담]
