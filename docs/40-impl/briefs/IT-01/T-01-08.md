**4.1-2 `decidePromotion(rules: MasteryRulesV1, inv: AssessmentInventory, s: PromotionSnapshot)`** — SP-6 `decidePromotion` 순서를 그대로 따르되:
1. `s.from + 1 > s.cap` → `cap_reached`, gate `CAP`(met false, value = from+1, threshold = cap, shortfall_ko `"v1 콘텐츠 상한(L{cap})"`).
2. `all` = `inv.concepts` 중 `level === from`, `required` = 그중 `required_for_level !== null`(contracts feasibility와 같은 정의). `all` 0개 → `rules.promotion.empty_level === 'skip'`이면 `promote`(gate `EMPTY_LEVEL_SKIP` met) · `'block'`이면 `not_ready`(gate `EMPTY_LEVEL` 미충족).
3. `required.length >= FR_PRG_013.sparse_required_lt` → gate `REQUIRED_MASTERED`: need = `neededMastered(rules, n)` = `n <= all_if_n_le ? n : min(n − allow_misses, ceil(ratio·n − ε))`(CR-20, ε = `rules.epsilon`), from === 4면 Mastered **∧ Retained** 개수로 판정. 아니면 희소 규칙: gate `SPARSE_DEPTH_EVIDENCE`(depth_evidence ≥ 1).
4. from === 2: gate `D4_DEPTH` — possible = `d4Possible`(d4_possible ∧ (`possible_scope === 'level_le_k'` ? level ≤ k : 전체)), need = `d4Required`(`min_with_possible`: max(min(2,p), min(5,p)) · `fixed`: max(2, min(5,p))), met = distinct d4 concept 수 ≥ need ∧ possible ≥ need.
5. from === 3: gate `CASE_L3` — OFFLINE이면 metric `d_fraction` ≥ 0.6, 그 밖 `rubric4` ≥ 2.5, level ≥ 3 Case 1개.
6. from === 4: gate `CASE_L4`(L4+ Case 서로 다른 2개 ≥ 3.0/4(OFFLINE d_fraction ≥ 0.75) ∧ (L5 Case ∨ 산출물 1개 ≥ 3.0 ∧ 반박 방어)) · gate `TAUGHT_OR_ARTIFACT`(Teaching ≥ 0.8 개념 ≥ 2 ∨ 산출물 ≥ 2개 평균 ≥ 3.0 ∧ 반박 방어 ≥ 1).
7. 사전 gate 하나라도 미충족 → `not_ready`, `can_start_assessment: false`. 전부 충족 + `assessment === null` → `not_ready`, `can_start_assessment: true`(= SP-6 `ready_for_assessment`).
8. assessment 있음 → `scoreAssessment` 결과로 gate `ASSESSMENT_ACCURACY`(correct ≥ `accuracy_min_correct[from]`) · `ASSESSMENT_CBM`(cbm_ratio ≥ `cbm_min[from]`) · `ASSESSMENT_FORMATS`(distinct ≥ `formats_min`) · `ASSESSMENT_ENGINE`(engine_ok) · 희소면 `SPARSE_LK_ACCURACY`(lk_correct/lk_items ≥ 0.8). 모두 met → provisional ? `promote_provisional` : `promote`, 아니면 `not_ready` + `can_start_assessment: true`.
9. provisional = 사용된 증거 중 하나라도 provisional(필수 Mastered ∩ `mastered_provisional_ids`, 사용된 D4·Case·Teaching·Artifact의 provisional). **강등 개념 0**: 함수는 현재 레벨을 낮추는 값을 만들지 않는다.
10. 모든 비교는 `geq(a, b, rules.epsilon)`. gate 객체 = `PromotionGate`(`gate_id` 정규식 `^[A-Z][A-Z0-9_]{1,40}$`, `label_ko` ≤ 80, 미충족이면 `shortfall_ko` 1문장·충족이면 null, `evidence_event_ids` ≤ 50). `profile = { policy_version, ai_mode: mode, sp1_state: sp1 }`. 반환 전 `gates.length ≤ 20` 단언.

**4.1-3 엔진·평가 구성** (CR-18·19, UT-LR-205·208)
- `rubricEngineFor`: `rules.ai_profiles[mode].rubric_engine[sp1 === 'pass' ? 'sp1_pass' : 'sp1_fail']`, provisional = engine === `'S_provisional'`.
- `assessmentFormatAllowed(rules, fmt, mode, sp1)`: `fmt.grade_class === 'D'` → true · `grade_class ∈ {J, S}` → `rules.assessment.engines`에 `'calibrated_jev_if_sp1_pass'` ∧ sp1 === `'pass'` ∧ mode ∈ {`FULL`,`JUDGE_ONLY`}일 때만 true · `H` → false. (LJ·S 엔진 0)
- `composeAssessment(rules, method: MethodFormats, pool: Readonly<Partial<Record<FormatId, number>>>, mode, sp1)` → `{ ok; plan: readonly FormatId[]; distinct_formats; reason: string | null }`: 허용 형식만, 수량 내림차순 → 동률은 FormatId 사전순 [Brief 결정, 결정성], 라운드로빈으로 `rules.assessment.items`개. 부족 → `reason 'pool <n>/<items>'`, 형식 수 < `formats_min` → `reason 'formats <d>/<min>'`.

**4.1-4 `scoreAssessment(rules, cbm: CbmParamsV1, from, items: readonly { correct: boolean; confidence: 1|2|3; format: FormatId; level: number }[])`** → `AssessmentResult & { cbm_ratio: number; accuracy_ok: boolean; cbm_ok: boolean }`: score_i = 정답 ? `cbm.score.correct[c−1]` : `cbm.score.wrong[c−1]`, max_i = `cbm.score.correct[c−1]`(선택한 확신도의 최대, `cbm_denominator: chosen_confidence_max`), `cbm_ratio = Σscore / Σmax`(음수 허용, Σmax = 0이면 0). 전부 C2 정답 = 1.0, C3로 12문항 중 2문항 오답 = (30−12)/36 = 0.5.

**4.1-5 `reconcileProvisional(levelNow: Level, regradePassed: boolean)`** → `{ level_after: levelNow; outcome: 'confirmed' | 'provisional_revoked'; needs_reconfirmation: boolean }` — 철회도 `level_after === levelNow`(BR-14), `provisional_revoked`면 `needs_reconfirmation: true`(`LevelProvisionalResolvedV1` refine과 일치).
