#### 4.1.4 `canonical/canonical.ts`

- `createFakePeer(opts: { peer: ServiceName; clock: Clock; handlers: Readonly<Record<string /* route id */, FakeHandler>> }): PeerClientPort & { readonly calls: readonly FakeCall[] }`.
- `FakeHandler = (input: PeerInput) => Result<PeerSuccess, PeerFailure>`; 핸들러 없는 route id 호출 = `Error('invariant: no fake handler for <id>')`.
- `FakeCall = { route_id, input, idempotency_key: string | null, deadline_header_ms: number | null, request_id: string | null }` — `deadline_header_ms = deadlineAt − clock.now() − 10`(IF §2.9). 이 값이 ≤ 0이면 핸들러를 부르지 않고 `{kind:'deadline_exhausted'}`를 돌려준다(실 PeerClient와 같은 규칙). `route.idempotent`인데 `idempotencyKey`가 없으면 `Error('invariant: …')`.
- 성공 body는 `route.response[status]`로 파싱해 돌려준다(실패 = `contract_violation`).

#### 4.2.5 `contract-arbitrary.ts` (결정적)
- `toJsonSchema(schema): object` — `z.toJSONSchema(schema, { unrepresentable: 'any' })`.

#### 4.2.6 egress 기록기·표본기 (TST §8.2·§8.3)
- `preload/egress-recorder.mjs`(Node `--import`로 싣는 ESM, 의존성 0): `net.Socket.prototype.connect`·`tls.connect`·`dns.lookup`·`dns.promises.lookup`·`globalThis.fetch`(URL 기록)·`child_process.{spawn,execFile,fork}`를 감싼다. 비 loopback 목적지(127.0.0.0/8·`::1`·`localhost`·unix 소켓 경로 외)와 비 node 바이너리 spawn(`process.execPath`·`node` 외)을 `<FATHOM_HOME>/tmp/egress/<pid>.jsonl`에 한 줄 JSON `{ts, pid, kind:'connect'|'tls'|'dns'|'fetch'|'spawn', target, blocked, stack}`(stack = 앞 5프레임)으로 `appendFileSync` 기록(preload이므로 동기 허용).
